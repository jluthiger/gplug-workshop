Betrieben von Infomaniak, einem Schweizer Anbieter. Eure Prompts und euer Code bleiben in der Schweiz.

Zugang steckt im Workshop-Image und gilt nur heute.

Bei jedem Prompt

  1. opencode schickt Auftrag und Rucksack.
  2. Das Modell antwortet: Text und Code-Änderungen.
  3. Es merkt sich nichts. Der Rucksack reist jedes Mal neu mit.

5 · Zuhause

Weiterbauen: das Minimum

Immer:

gPlug im Heim-WLAN · Workshop-Ordner · IP in .gplug

Ohne KI

Texteditor + Browser · gratis

  1. app/spot.be im Editor ändern.
  2. WebUI: Werkzeuge → Dateisystem verwalten → hochladen.
  3. Konsole: BrRestart, dann prüfen.

BRY: = Meldung von Berry. „Berry initialized“ und „Successfully loaded“ sind normal. BRY: mit Fehler und Zeilennummer: diese Zeile in spot.be ansehen.

oder ./upload.sh + ./log.sh

Mit KI

Docker + eigener Zugang · bezahlt pro Token

  1. AI Tools aktivieren, Ausgabenlimite setzen.
  2. API-Token erstellen, mit Product-ID als Variablen setzen.
  3. ./docker-run.sh: Auftrag, Rucksack, Resultat wie heute.

API-Token: dein Schlüssel, geheim wie ein Passwort. Tokens: Textstücke (≈ ¾ Wort), die das Modell liest und schreibt. Danach zahlst du.
